# 🚗 자동차 뉴스

국내 자동차 뉴스 10개와 해외 자동차 뉴스 10개를 매시간 자동으로 모아 보여 주는 앱입니다.
해외 기사는 제목을 한국어로 번역해 보여 주고, 누르면 원문 기사로 이동합니다.

**앱 주소: https://hicsh10.github.io/car-news/**

## 휴대폰·PC에 설치하기

| 기기 | 방법 |
| --- | --- |
| 아이폰 | Safari로 주소 열기 → 아래 **공유** 버튼 → **홈 화면에 추가** |
| 안드로이드 | Chrome으로 주소 열기 → 화면의 **설치** 버튼 또는 메뉴(⋮) → **앱 설치** |
| PC (Chrome·Edge) | 주소 열기 → 주소창 오른쪽 **설치** 아이콘 클릭 |

설치하면 홈 화면·바탕화면에 아이콘이 생기고, 일반 앱처럼 열립니다.

## 동작 방식

- GitHub Actions가 매시간 `fetch_news.py`를 실행해 Google 뉴스에서 기사를 모으고 `news.json`을 갱신합니다.
- 할인·프로모션 같은 광고성 기사와 중복 기사는 자동으로 걸러집니다.
- 해외 기사 제목은 자동 번역됩니다. 번역이 실패하면 영어 제목이 그대로 표시됩니다.
- 검색어를 바꾸려면 `fetch_news.py` 위쪽의 `FEEDS`만 고치면 됩니다.
- 지금 바로 갱신하려면 **Actions → 자동차 뉴스 업데이트 → Run workflow**를 누르세요.
